# `long long` 与防溢出

`long long` 至少为 64 位；竞赛环境通常是 64 位有符号整数。算术结果越界之前就要判断边界，不能计算后再检查。

## 算法模板

```cpp
#include <cassert>
#include <limits>
using i64 = long long;

// a、b、limit 均非负。判断 a*b 是否不超过 limit。
bool product_fits(i64 a, i64 b, i64 limit) {
    assert(a >= 0 && b >= 0 && limit >= 0);
    return b == 0 || a <= limit / b;
}
```

最短路的无穷大应结合合法距离上界选择，且加法前应检查距离有效、结果可表示。`memset` 按字节写入，`memset(dist, 0x3f, sizeof dist)` 在 64 位数组中得到的是 `0x3f3f3f3f3f3f3f3f`，不能仅凭 `0x3f` 判断它的数值大小。

`string::size()` 和容器 `size()` 返回对应容器的 `size_type`（通常是无符号的 `size_t`），不是 `int`。需要有符号运算时显式转换，并确认长度和运算结果在目标类型范围内。

## 使用示例

```cpp
#include <iostream>
#include <string>
int main() {
    std::string text = "abc";
    i64 pairs = i64(text.size()) * 2;
    std::cout << pairs << '\n';                      // 6
    std::cout << product_fits(1000000000LL, 1000000000LL,
                             std::numeric_limits<i64>::max()) << '\n'; // 1
}
```

将算法模板与示例放入同一个文件即可编译。`product_fits` 的时间、空间复杂度均为 O(1)。对更宽的中间结果，可在 GCC/Clang 中使用 `__int128`，参见 128 位整数模板。
