# 竞赛算法模板

每份代码按同一顺序组织：**算法简介 → 算法模板 → 使用示例**。顶部说明用途、复杂度和前提；中间保留可复制实现；底部用固定小数据演示调用，并标明预期结果。

## 统一规范

- **语言**：C++17，使用标准头文件；`__int128` 与位扫描内建函数需要 GCC/Clang。
- **命名**：文件名使用算法名，变体用全角括号 `（…）`；类型使用 `PascalCase`，函数、变量使用 `snake_case`，常量使用 `kPascalCase`。算法缩写保留常用大写形式。
- **格式**：4 空格缩进、大括号同行；本目录的 [.clang-format](.clang-format) 负责格式化。
- **整数**：下标通常使用 `int`，较大数值使用 `i64`；不使用 `#define int long long` 或本地调试头文件。数据规模须能由下标类型表示，数值范围遵循各模板的约定。
- **边界**：数组、图顶点默认从 0 开始，区间默认是半开区间 `[l,r)`；闭区间、排名等例外在文件顶部单独说明。
- **复制**：复制所需的头文件、类型别名和“算法模板”部分，再按底部示例调用。合并多份模板时保留所需定义并去除重名项。
- **示例**：`.cpp` 可直接编译运行；[比赛起手.hpp](比赛起手.hpp) 的示例通过 `TEMPLATE_EXAMPLE` 宏启用。

通用线段树保留原有的多组 `Info` / `Tag` 组合，复制框架和需要的一个命名空间即可。`Info{}` 是空区间单位元，有效数值叶子应显式使用 `Info(value)`。常用模板组合用于集中参考，日常复制优先选择专题文件。

## 编译示例

在仓库根目录运行：

```sh
c++ -std=c++17 -O2 -Wall -Wextra TEMPLATE/KMP.cpp -o /tmp/kmp
/tmp/kmp
# 输出：0 2
```

比赛起手头文件也可直接包含。运行其内置示例：

```sh
printf '#define TEMPLATE_EXAMPLE\n#include "TEMPLATE/比赛起手.hpp"\n' > /tmp/template_example.cpp
c++ -std=c++17 -O2 -Wall -Wextra -I. /tmp/template_example.cpp -o /tmp/template_example
/tmp/template_example
# 输出：6
```

格式化自有代码（不包含第三方目录）：

```sh
clang-format -i TEMPLATE/*.cpp TEMPLATE/*.hpp
```

检查所有 `.cpp` 示例（任一编译或运行失败都会停止）：

```sh
for source in TEMPLATE/*.cpp; do
    c++ -std=c++17 -O2 -Wall -Wextra -Werror "$source" -o /tmp/cp_template_example || exit 1
    /tmp/cp_template_example || exit 1
done
```
