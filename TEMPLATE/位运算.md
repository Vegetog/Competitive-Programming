# 位运算

对无符号整数按位计算，常用于状态压缩、集合枚举和快速取位。以下使用 `uint64_t`，单次操作时间、空间均为 O(1)。

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `&` | 按位与 | `(0b110 & 0b101) == 0b100` |
| `\|` | 按位或 | `(0b110 \| 0b101) == 0b111` |
| `^` | 按位异或 | `(0b110 ^ 0b101) == 0b011` |
| `~` | 按位取反 | 对全部 64 位取反 |
| `<<` | 左移 | `uint64_t{1} << 3 == 8` |
| `>>` | 右移 | `uint64_t{8} >> 2 == 2` |

## 算法模板

```cpp
#include <cstdint>
using u64 = uint64_t;

bool has_bit(u64 mask, int bit) { return (mask >> bit) & 1; }
u64 set_bit(u64 mask, int bit) { return mask | (u64{1} << bit); }
u64 clear_bit(u64 mask, int bit) { return mask & ~(u64{1} << bit); }
u64 lowbit(u64 mask) { return mask & (u64{0} - mask); }
```

约定：位编号从 0 开始，必须满足 `0 <= bit < 64`。移位表达式的类型取决于左操作数及整数提升；使用 `uint64_t{1}` 可避免 `1 << bit` 的 32 位宽度限制。有符号负数的右移在 C++17 中由实现决定，位运算优先使用无符号类型。

## 使用示例

```cpp
#include <cassert>
int main() {
    assert(has_bit(0b1010, 3));
    assert(set_bit(0b1010, 0) == 0b1011);
    assert(clear_bit(0b1010, 1) == 0b1000);
    assert(lowbit(0b1010) == 0b0010);
}
```

复制“算法模板”与“使用示例”即可编译运行。比较运算与位运算混用时请显式加括号，例如 `(mask & 1) == 0`。
